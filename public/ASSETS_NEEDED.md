# Assets needed

This project references image/file paths that don't exist yet as binary files
(I can't generate real photos/PDFs in this environment). Add these to `public/`
to complete the site — everything will render with graceful gradient
placeholders until you do.

| Path | What to add |
|---|---|
| `/og-image.png` | 1200x630 social share image |
| `/resume-chetan-naik.pdf` | Your resume, referenced by the download buttons |
| `/projects/*.jpg` | Screenshots for each project in `src/data/projects.ts` |
| `/videos/*.jpg` | Thumbnails for each video in `src/data/media.ts` |
| `/certs/*.jpg` | Certificate images in `src/data/resume.ts` |

None of these are required for the site to build or run — components already
have gradient/icon fallbacks — but adding them will make the Projects,
YouTube, and Certificates sections feel complete.
